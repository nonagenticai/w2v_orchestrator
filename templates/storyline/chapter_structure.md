# Chapter Structure Guidelines

Each chapter should follow this pattern:

1. **Chapter title card** (3-5 seconds)
   - Shows chapter number, title, and subtitle
   - Gradient background matching the theme

2. **Navigation** (5-10 seconds)
   - Navigate to the relevant page
   - Show the URL and page title
   - Wait for page load

3. **Overview** (10-15 seconds)
   - Annotation explaining what this page is
   - Slow scroll to show full page layout
   - Highlight the main content area

4. **Interactions** (20-40 seconds)
   - Demonstrate key interactive elements
   - Fill forms with demo data
   - Click buttons (without submitting)
   - Show hover states and tooltips

5. **Key takeaway** (5-10 seconds)
   - Final annotation summarizing the chapter
   - Smooth transition to next chapter
