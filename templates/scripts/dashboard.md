# Dashboard Demo Patterns

When recording a dashboard/app page:

1. **Navigate** — Go to the dashboard
2. **Overview** — Annotate what the dashboard shows
3. **Key metrics** — Highlight stat cards or KPIs
4. **Charts** — Hover over chart elements to show tooltips
5. **Navigation** — Show sidebar/tab navigation
6. **Actions** — Demonstrate key actions (filters, dropdowns, buttons)
7. **Data tables** — Scroll through data if present
