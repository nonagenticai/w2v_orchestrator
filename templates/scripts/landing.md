# Landing Page Demo Patterns

When recording a landing page:

1. **Hero section** — Navigate and wait for load, annotate the value proposition headline
2. **Feature highlights** — Scroll to feature section, highlight 2-3 key features
3. **Social proof** — Show testimonials, stats, or client logos with annotations
4. **CTA buttons** — Highlight the primary call-to-action buttons (top and bottom)
5. **How it works** — Scroll to comparison or how-it-works section, annotate each step
6. **Bottom CTA** — Scroll to the bottom signup form or CTA, annotate it

Use `smoothScroll` to move between sections naturally. Annotate the value proposition first — the hero message is the most important element.
