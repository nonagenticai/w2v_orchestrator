# FAQ Page Demo Patterns

When recording a FAQ page:

1. **Page heading** — Navigate and annotate the FAQ page title
2. **Expand items** — Click to expand 2-3 accordion items to reveal answers
3. **Search/filter** — Demonstrate the search or filter feature if available
4. **Categories** — Scroll through category sections if the FAQ is organized by topic
5. **Contact CTA** — Highlight any "still have questions?" or contact support link

Pause briefly after expanding each FAQ item so the viewer can read the answer. Use `pause(page, 3000)` after expanding each item.
