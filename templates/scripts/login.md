# Login Page Demo Patterns

When recording a login page:

1. **Login form** — Navigate and show the login form layout
2. **Form fields** — Annotate the username/email and password fields
3. **Forgot password** — Highlight the "forgot password" link
4. **Social login** — Show social login buttons (Google, GitHub, etc.) if present
5. **Sign up link** — Highlight the "create account" or "sign up" link
6. **Submit button** — Annotate the submit button

Do NOT enter real credentials. Use `slowType` with placeholder text like "user@example.com" if demonstrating form interaction. Do NOT submit the form.
