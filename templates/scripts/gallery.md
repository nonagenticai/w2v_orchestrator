# Gallery Page Demo Patterns

When recording a gallery or portfolio page:

1. **Grid overview** — Navigate and show the gallery grid layout
2. **Open items** — Click on 2-3 items to open the lightbox or detail view
3. **Navigate items** — Use next/previous navigation within the lightbox
4. **Close lightbox** — Close the detail view and return to the grid
5. **Filters** — Demonstrate filtering or category selection if available
6. **Full scroll** — Scroll through the full gallery to show the range of content

Pause in the lightbox view so the viewer can see the full-size image. Use `highlightElement` on the filter controls.
