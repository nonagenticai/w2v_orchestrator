# Homepage Demo Patterns

When recording a homepage:

1. **First impression** — Navigate, wait for load, annotate the value proposition
2. **Hero section** — Highlight the hero area, read the main heading
3. **Navigation** — Show the main menu items
4. **Features grid** — Scroll to features, highlight each feature briefly
5. **Social proof** — Show testimonials, client logos, or stats
6. **CTA** — Highlight the primary call-to-action button
7. **Footer** — Quick scroll to footer, show contact/social links

Use `smoothScroll` to move through sections naturally.
