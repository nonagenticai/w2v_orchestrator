# Pricing Page Demo Patterns

When recording a pricing page:

1. **Page header** — Navigate and annotate the pricing headline
2. **Pricing tiers** — Highlight each pricing tier, hovering over features per tier
3. **Billing toggle** — If monthly/annual toggle exists, demonstrate switching it
4. **Recommended plan** — Highlight the recommended or most popular plan
5. **Feature comparison** — Scroll to the feature comparison table, annotate key rows
6. **CTA per tier** — Annotate the CTA buttons for each plan

Pace slowly through each tier so viewers can read prices and features. Use `highlightElement` on the recommended plan badge.
